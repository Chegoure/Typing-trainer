# Тренажёр слепой печати <touch></typing>

Тренажёр для **практики** слепой печати на своём тексте.

Не учит раскладке и не даёт уроков — просто вставляете любой текст (код, статью, заметки) и печатаете.

## Возможности

- Свой текст для тренировки
- Готовый текст для тренировки
- Подсветка верных и ошибочных символов
- Корректная работа пробела, Tab и Enter (включая пустые строки)
- Окно из 3 строк эталона + текущая строка ввода
- Режим «Тишина» — только набор, без лишнего UI
- Возможность скрыть инпут
- Переключение курсора: статика / мигание
- Скорость, точность, ошибки, прогресс

## Как пользоваться

Онлайн — откройте страницу [Тренажёр слепой печати](https://chegoure.github.io/touch-typing/)

Офлайн — скачайте `touch-typing.html` и откройте в браузере. Интернет не нужен: всё работает локально в одном файле.
